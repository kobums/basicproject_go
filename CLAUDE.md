## Project Overview

Go REST API starter template (basicproject_go): Fiber v2, Go 1.26, MariaDB. The template owns only auth/infra
(login/signup/me, upload, health, DB pool, config, logging). All table CRUD is generated by gomachine
(`buildtool-model`) from `db/schema.sql` + `model.json`. See README.md (Korean) for the full guide.
gomachine's `buildtool-model init` (workspace mode) copies this repo as a project's Go backend, so nothing here may
depend on paths outside the repo. Go API port 8007; the sibling Spring / Rust templates use 8081 / 8008 with the same API.

## Commands

```bash
cp .env.example .env   # first time; JWT_SECRET must be >= 32 bytes
make db-up             # MariaDB via docker compose (db/schema.sql runs on first start)
make gen               # buildtool-model . go (needs the DB and ~/bin/buildtool templates; output is gofmt'd, regen is diff-free)
make run               # go run .
make build             # bin/basicproject_go
make test              # go test ./...
make vet / make fmt
make docker            # docker build; make docker-up = compose db + api (profile "api")
```

## Generated vs hand-written files

- Generated by gomachine (first line `// Code generated by gomachine. DO NOT EDIT.`): `models/{table}.go`,
  `models/{table}/{table}.go`, `controllers/rest/{table}.go`, `router/routers/{table}.go`, `router/routers/generated_routes.go`.
  Do not edit them; change `db/schema.sql` / `model.json` and run `make gen`. Commit the regenerated files.
- Hand-written (gomachine never overwrites them): everything else, notably `models/db.go`, `controllers/controllers.go`,
  `router/router.go`, `router/routers/{auth,auth_middleware,upload}.go`, `global/**`.

## Access rules (model.json, enforced by generated code)

- `board`: `session` (author = `c.Session.Id`) + `read: "login"` + `join` user. Anonymous reads → `auth error`;
  any logged-in user reads all rows (author in `extra.user`); update/delete/batch delete only by the author (else `auth error`).
- `user`: non-admins read only their own row (`u_id = session id` on list/count/search, other `GET /:id` → `auth error`);
  admins (`Level >= adminLevel` 3) read all. `level` is protected: inserts get the DB default 1, only admins change it.
- String list filters are partial matches (`like '%v%' escape '!'`).

## Auth / upload API contract (gomachine README "인증 API 계약"; keep identical to Spring / Rust templates)

- `POST /api/auth/signup` → 201 `{token, tokenType:"Bearer", expiresInMs, user}`; 400 validation (`fieldErrors`), 409 duplicate email.
- `POST /api/auth/login` → 200 same shape | 401. `GET /api/auth/me` → 200 `user` | 401.
- `user` = `{id, email, name, level, createddate}` (`controllers/dto`, same keys as generated `models.User`, no password).
- Errors: HTTP status + `{status, message, fieldErrors?}` (`router/routers/auth_middleware.go`).
- `POST /api/upload/index` multipart field `upload` (JWT) → 200 `{filename, url}`, `url` = `/uploads/{filename}`
  (stored in `{UPLOAD_PATH}/uploads`, served statically).

## Tests

`services/*_test.go` run the full Fiber app without MariaDB: `services/standin_test.go` registers a `database/sql`
driver (`standin`) that records every query/exec and returns rows the test supplies. Use it to assert what SQL the
generated code sends (e.g. self filter, no write on someone else's row).

## Architecture

- `main.go` — validates config (`config.Validate`: JWT_SECRET length, DB name) then starts `services.Http()`.
- `services/http.go` — `NewApp()` builds the Fiber app (CORS incl. Authorization/PATCH, 20MB body limit, compress, static, routes).
- `router/router.go` — `/api/health`, `SetupAuthRoutes`, `SetupUploadRoutes`, `SetupGeneratedRoutes`.
- `controllers/controllers.go` — base `Controller`; `Init` fills `Session *Session{Id int64, Email string, Level int}`
  from `Authorization: Bearer` (nil when absent/invalid). Generated controllers rely on this contract.
- `global/jwt` — unified JWT (HS256, claims `{sub, id, email, level, iat, exp}`), golang-jwt/v5, bcrypt `GeneratePasswd`.
- `global/config` — env-first config: `.env` file → env vars → optional `.env.yml`.
- `models/db.go` — one shared `*sql.DB` pool; `Connection.Close` only rolls back an open tx. Provides the API generated
  models need: `Where`, `WhereClause`, `ValidColumn`, `Custom{Query, Params}`, `Paging`, `Ordering`, `Connection`.

## Adding a table

1. Add `CREATE TABLE {name}_tb` with `{prefix}_` columns to `db/schema.sql` and apply it to the dev DB.
2. Optionally add `{ "name": ..., "session": [...], "read": "owner|login|public", "join": [...], "protect": [...] }` to `model.json`.
3. `make gen`, then `make test`.
